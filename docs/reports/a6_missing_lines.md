# A6 누락 노선 점검

- 작성: 2026-11-05 (3차 무인 세션). 표준데이터 기준일 2026-06-30, 다국어 역사정보 기준일 2026-07-01.
- 결론: **표준데이터에 빠진 개통 노선은 GTX-A 하나.** 개통이 확인된 두 구간(9역, 엣지 7개)만 추가했다. 서울역–수서 연결은 개통을 확인하지 못해 넣지 않았다.

## 방법과 근거

| 근거 | 내용 | 결과 |
| :- | :- | :- |
| 1. 레일포털 다국어 역사정보 (자동 수집, `stations_metro.xlsx`) | 표준데이터 역과 매칭 안 된 행 62개 분류 + `신설일자` 2023-06 이후 행 전수 | GTX-A 9행(X101~X111, X104 창릉·X107 삼성 결번)만 표준데이터에 노선이 없음. 나머지 신설역(별내선, 대경선, 대구1호선 하양 연장, 인천1호선 검단 연장, 경의중앙 파주, 대경선 북삼 등)은 전부 표준데이터에 있음 |
| 2. Wikidata (SPARQL, CC0) | 한국(Q884) 역 중 P1619(개통일) ≥ 2024-01-01 전수 | 17개 역. GTX-A 운정중앙·킨텍스(2024-12-28)만 우리 데이터에 없었고, 중부내륙선 2역은 도시철도 스코프 밖 |
| 3. Wikidata GTX-A(Q22974067) 역 | P81 = GTX-A인 역의 P1619·P197·P296 | 성남 2024-03-30 개통, P197 성남–수서·성남–구성. 운정중앙·킨텍스 2024-12-28, 역번호 X101·X102 |
| 4. 표준데이터 환승노선명 텍스트 | 서울역(경의선)·성남역·구성역에 'GTX-A' 기재 | GTX-A 존재의 간접 근거 (환승노선번호는 비어 있음) |
| 5. 웹 검색 (WebSearch 도구) | 서울역–수서 연결, 2026 개통 예정 노선 | 아래 의심 목록. 개통 확인 자료 없음 |

OSM(Geofabrik 추출본)은 세션 네트워크에서 TLS 단계 차단이라 쓰지 못했다 (A5 참고).

## 추가한 것 (`config/kr_supplement.yaml` → 02·03 단계)

| 구간 | 역 (역번호) | 개통 근거 (2개 이상) |
| :- | :- | :- |
| 북부 | 운정중앙(X101) – 킨텍스(X102) – 대곡(X103) – 연신내(X105) – 서울역(X106) | 다국어 파일 신설일자 2024-12-28 (5역 모두), Wikidata P1619 2024-12-28 (운정중앙·킨텍스) |
| 남부 | 수서(X108) – 성남(X109) – 구성(X110) – 동탄(X111) | 다국어 파일 신설일자 수서·성남 2024-03-29, 구성 2024-06-29. Wikidata 성남 P1619 2024-03-30, P197 성남–수서·성남–구성 |

- 역 레코드: 다국어 파일 행 그대로 (한글·영문·로마자·일본어·중국어 간체/번체명, 좌표, 주소, 환승 여부). 이 파일의 GTX-A 행은 대부분 위·경도 열이 뒤바뀌어 있어 바로잡았다.
- 순서: 역번호 오름차순과 같다. 역간 직선거리(5.9~11.0km)가 다국어 파일 상·하행 거리(선로 km, 6.1~10.7km)보다 약간 짧아 정합적이다.
- 공식 환승 정보: 다국어 파일 '환승노선명' 텍스트(예: 대곡 '3호선,서해선,경의중앙')를 표준데이터 코드 체계로 옮겨 A3 규칙에 넣었다 (`transfer_text_codes`).
- 결과: 대곡·연신내·서울역·수서·성남·구성은 기존 환승역 클러스터에 합류, 운정중앙·킨텍스·동탄은 단독역. 클러스터 938 → 941, 승차 엣지 +7. 새 포탈은 없다 (같은 이름 역이 다른 도시에 없음).
