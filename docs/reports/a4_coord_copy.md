# A4 좌표 복사 전수 점검

생성: `python3 pipeline/12_audit_transfers.py` (기준: `config/validation.yaml` coord_copy)

정규화 이름이 같고 좌표 차이 20m 미만인데 공식 환승역(yes)이 아닌 역 레코드 쌍 전부. 2차에서 고친 동해선 동래(4호선 동래와 7m)가 이 패턴이었다.

결과: 5쌍

| 유형 | 쌍 |
| :- | -: |
| 같은 노선 패밀리 레코드 (직결 경계·그룹 분할) — 같은 역, 정상 | 4 |
| 공식 정보 불완전 — 판정 보류 | 1 |

| 이름 | A | B | 거리(m) | 공식 관계 | 같은 클러스터 | 유형 |
| :- | :- | :- | -: | :- | :- | :- |
| 광운대 | 광운대역[경원선] | 광운대역[경춘선] | 16.2 | same_line | 예 | 같은 노선 패밀리 레코드 (직결 경계·그룹 분할) — 같은 역, 정상 |
| 논현 | 논현[신분당선] | 논현[7호선] | 1.9 | unknown | 예 | 공식 정보 불완전 — 판정 보류 |
| 용산 | 용산역[경부선] | 용산역[경원선] | 0.0 | same_line | 예 | 같은 노선 패밀리 레코드 (직결 경계·그룹 분할) — 같은 역, 정상 |
| 중랑 | 중랑역[경의중앙선] | 중랑역[경춘선] | 0.0 | same_line | 예 | 같은 노선 패밀리 레코드 (직결 경계·그룹 분할) — 같은 역, 정상 |
| 지축 | 지축[3호선] | 지축역[일산선] | 4.1 | same_line | 예 | 같은 노선 패밀리 레코드 (직결 경계·그룹 분할) — 같은 역, 정상 |

## 검출력 확인 — 이미 고친 좌표를 원래 값으로 되돌렸을 때

이름이 같은 짝이 없는 복사(마곡 = 발산 좌표, 이촌 = 신용산 좌표)는 이 검사 범위 밖이고 2차 근접 중복 검사(다른 클러스터 30m 이내)가 잡는다.

| 보정된 역 | 이 검사로 검출 | 걸린 쌍 |
| :- | :- | :- |
| 이촌(국립중앙박물관)[4호선] | 아니오 | - |
| 동래역[동해선] | 예 | 동래역[동해선]–동래[부산 경량도시철도 4호선] 8.1m no |
| 양원역[경의중앙선] | 아니오 | - |
| 마곡[5호선] | 아니오 | - |
