# 경로 예시 — ruleset `strict`

생성: `python3 pipeline/05_route.py --examples`

```
목동 → 부산 동래 (워프 허용)
  총비용 12 = 승차 9역 + 워프 3회 (환승 비용 0)
  [5호선] 목동 → 양평 (2역)
    ⇢ 워프 T1 [양평]: 수도권 양평 ⇢ 수도권 양평역
  [경의·중앙선] 양평역 → 용문역 (2역)
    ⇢ 워프 T1 [용문]: 수도권 용문역 ⇢ 대전 용문
  [대전 1호선] 용문 → 시청 (2역)
    ⇢ 워프 T1 [시청]: 대전 시청 ⇢ 부산 시청(연제)
  [부산 1호선] 시청(연제) → 동래 (3역)
```

```
목동 → 부산 동래 (워프 없음)
  연결 안 됨: 목동#1 와 동래#1|동래#2 는 같은 컴포넌트가 아니다
```

```
강남 → 부산 동래 (워프 허용)
  총비용 3 = 승차 2역 + 워프 1회 (환승 비용 0)
  [2호선] 강남 → 교대(법원·검찰청) (1역)
    ⇢ 워프 T1 [교대]: 수도권 교대(법원·검찰청) ⇢ 부산 교대
  [부산 1호선] 교대 → 동래 (1역)
```

```
강남 → 부산 동래 (워프 없음)
  연결 안 됨: 강남#1 와 동래#1|동래#2 는 같은 컴포넌트가 아니다
```

```
개화 → 광주 녹동 (워프 허용)
  총비용 15 = 승차 14역 + 워프 1회 (환승 비용 0)
  [9호선] 개화 → 김포공항 (1역)
    환승: 김포공항(서울 도시철도 9호선) → 김포공항역(서해선)
  [서해선] 김포공항역 → 대곡역 (2역)
    환승: 대곡역(서해선) → 대곡역(일산선)
  [3호선 일산선] 대곡역 → 화정역 (1역)
    ⇢ 워프 T1 [화정]: 수도권 화정역 ⇢ 광주 화정
  [광주 1호선] 화정 → 녹동 (10역)
```

```
개화 → 광주 녹동 (워프 없음)
  연결 안 됨: 개화#1 와 녹동#1 는 같은 컴포넌트가 아니다
```
