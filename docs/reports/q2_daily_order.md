# Q2 데일리 퍼즐 다양성 — daily_order 재구성

생성: `python3 pipeline/10_build_game_data.py` (일정) → `python3 scripts/q2_compare.py` (이 비교표). 설정 `config/game.yaml` puzzles.daily_order

## 정의

- **풀이 시그니처**: 최적 경로에 쓰인 포탈 순서 (예: `중동+동백`). 포탈 집합은 순서를 뺀 것.
- **보정 난이도** (3차 직관 탐색): 점수 = 최적 비용 / 지리 감각 최선 우선 탐색(역의 가치 = 그 역이나 그 역의 워프 도착지에서 목적지까지 대권거리의 최솟값)이 찾은 경로 비용. 1.0 = easy, 0.4 이상 = normal, 그 밖 = hard. **난이도 지수 h = 1 − 점수** (0 = 지리 감각대로 가면 최적, 1에 가까울수록 감각과 반대로 가야 함).
- 제약 (전부 182일 순환 일정 기준, 마지막 날 다음은 첫날): (i) 같은 시그니처 간격 ≥ 14일, (ii) 연속한 두 날 포탈 집합 자카드 ≤ 0.34, (iii) 30일 창마다 포탈별 등장 ≤ 4, (iv) 요일별 허용 보정 난이도:

| 요일 | 허용 등급 | 목표 h |
| :- | :- | -: |
| 월 | easy | 0.0 |
| 화 | easy, normal | 0.3 |
| 수 | normal | 0.45 |
| 목 | normal | 0.55 |
| 금 | normal, hard | 0.58 |
| 토 | hard | 0.72 |
| 일 | hard | 0.8 |

- 풀이: 탐욕 배치(날마다 하드 제약을 지키는 후보 중 소프트 비용 최소 — 목표 h 차이, 30일 안 같은 포탈 재사용의 거리 역수 합, 흥미도) → 국소탐색(위반 난 날을 미사용 후보로 교체하거나 다른 날과 교환, (위반 수, 소프트 비용) 사전식 감소). ILP는 쓰지 않았다 (탐욕+국소탐색으로 위반 0).
- 풀: 종류(shortcut/crosscity) × 규칙 난이도마다 흥미도 순 {'shortcut': 90, 'crosscity': 70}, 같은 시그니처 등급마다 2개, 같은 출발/도착 역 3번까지 → 374개 중 182개를 일정에 쓴다.
