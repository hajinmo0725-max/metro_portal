# R4 LOOM(octi) vs 자체 MIP 도식 비교

생성: `python3 scripts/loom_compare.py` · LOOM 커밋 `1e4757838104d1e4d22186c9b77d5fc4b98681a0` (환경 설정 스크립트가 빌드한 `/tmp/loom/build`의 실행 파일을 외부 CLI로만 사용, GPL-3.0, 코드 미복사) · 파이프 `loom | octi --geo-pen 0 | transitmap -l` (octi 기본: 휴리스틱, 8방향 격자, 차수 2 축약)

- octi 출력은 경위도라 웹 메르카토르로 투영하고, 꺾이는 곳의 둥근 모서리(짧은 선분 여러 개)는 더글러스–포이커 40m로 단순화한 뒤 잰다. '8방향'은 각도 오차 2° 이내 (단순화가 남긴 어긋남 허용) — LOOM 쪽 8방향·엣지 안 꺾임 수치는 근사다.
- LOOM은 엣지를 격자 위 폴리라인으로 그리므로 '8방향 아님'은 선분 단위, 교차는 정점을 공유하지 않는 선분 쌍. 굴곡은 우리 지표와 같은 정의(노선 시퀀스의 역 좌표에서 꺾인 각도, 45° 단위 합) + 엣지 안쪽 꺾임을 따로 센다.
- 자체 MIP는 역 사이를 직선으로 잇는다 (엣지 안쪽 꺾임 0). 교차는 엣지 쌍 기준(지리 좌표에도 있는 입체 교차 포함).
