# R4 라벨 배치 전후 비교

생성: `python3 scripts/label_compare.py`. 같은 도식 좌표(캐시)에서 4차 배치(라벨·역 원 겹침만 비용)와 5차 배치(+ 노선 선분이 라벨 안을 지나는 길이 × 0.45·글자 높이, 8방위 후보 추가)를 비교한다.

- 선 위 라벨: 라벨 사각형 안을 노선 선분이 2px 넘게 지나는 라벨 수. 겹침 쌍: 라벨 외접 사각형끼리 0.5px 넘게 겹치는 쌍 수.
- 1100px = 보고서 SVG 크기. 3300px = 웹 수도권 기본 확대(3배, 글자 크기 고정)와 같은 간격.

| 권역 | 화면 폭 | 라벨 | 선 위 라벨 4차 → 5차 | 겹침 쌍 4차 → 5차 |
| :- | -: | -: | :- | :- |
| 수도권 | 1100 | 655 | 302 → **221** | 843 → **681** |
| 수도권 | 3300 | 655 | 159 → **28** | 71 → **46** |
| 부산 | 1100 | 146 | 12 → **0** | 9 → **0** |
| 대구 | 1100 | 97 | 12 → **1** | 6 → **1** |
| 대전 | 1100 | 22 | 0 → **0** | 0 → **0** |
| 광주 | 1100 | 20 | 1 → **0** | 1 → **0** |
| 타이베이 | 1100 | 170 | 27 → **4** | 11 → **2** |
