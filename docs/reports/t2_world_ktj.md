# T2 한국 + 타이베이 + 도쿄 통합 그래프 — ruleset 비교

생성: `python3 pipeline/17_compare_world_rulesets.py --config config/world_compare_ktj.yaml` (룰 `config/rulesets/ktj_*.yaml`)

- 4차(2026-11-06 사용자 결정 Q6-1): 기본 3종(`tw_t1`, `tw_t12`, `tw_t123`)은 이름 출처 등급 **official + native_label**을 쓴다. 타이베이 역의 zh-Hant Wikidata 라벨은 현지어 라벨(준공식)로 인정하고, 현지어가 아닌 라벨(en 등)은 T3a에서만 쓰며 그 포탈은 신뢰도 low로 표시한다.
- 참고: `tw_t12_official`은 공식명만(3차 기본 재현), `tw_t123b`는 T3b(로마자 표기 우연 일치)를 켠 것이다.
- 비용: 승차 1, 환승 0, 워프 T1 1·T2 2·T3a/T3b 3. 환승 판정은 공식 우선 + 역외 환승 수동 목록(타이베이는 공식 환승 정보가 없어 거리 D=500).
- 한국 쪽 T2 = 표준데이터 한자역사명, T3 = 표준데이터 영문역사명. T3a = 번역형 영어명(City Hall), T3b = 로마자형 (판정: ruleset translation_words). 같은 클러스터 집합을 더 싼 등급이 이미 잇고 있으면 비싼 등급 포탈은 만들지 않는다(dedupe).
