# N4 ruleset 비교 — 환승 비용 × 환승 판정 거리 D

생성: `python3 pipeline/09_compare_rulesets.py` (격자: `config/ruleset_grid.yaml`, base `strict`). 기준 조합: 환승 0, D=500m (= 현재 strict).

지표는 클러스터(물리적 역) 수준. 환승 비용 1일 때 지름·평균 비용은 역 수준 그래프에서 계산해 환승 비용이 반영된다.

## 4. D에 따라 클러스터 수가 바뀌는 이름 (환승 비용 0)

| 부전 | 2 | 1 | 1 |
